# Sentinel Frontend

Frontend Angular para o teste técnico **Sentinel — Modern Incident Management Platform**.

## Stack

- Angular
- TypeScript
- SCSS
- Angular Router
- Reactive Forms
- HttpClient
- Standalone Components

## Rodar

```bash
npm install
npm start
```

Aplicação:
```bash
http://localhost:4200
```

Backend esperado:
```bash
http://localhost:3333/api
```

Swagger:
```bash
http://localhost:3333/docs
```

## Estrutura

```txt
src/app
  core
  features/incidents
  shared
```
